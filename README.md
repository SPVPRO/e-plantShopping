# e-plantShopping

## Paradise Nursery Shopping Application 🌱

This project is a React-based shopping cart application for an online plant shop.  
It allows users to browse different categories of houseplants, add them to a cart, and manage quantities dynamically.

### Features
- Landing page with navigation to product listing and cart
- Product listing page with plant cards (image, name, description, cost)
- Categories such as Aromatic Plants, Medicinal Plants, etc.
- Shopping cart with:
  - Increment/decrement quantity
  - Remove items
  - Continue Shopping and Checkout buttons
- Redux Toolkit integration for state management
- Deployed using GitHub Pages

### Repository
This repository is named **e-plantShopping** and contains all project files including:
- `App.jsx`
- `App.css`
- `ProductList.jsx`
- `CartSlice.jsx`
- `CartItem.jsx`
- `AboutUs.jsx`

### Deployment
The application is deployed on GitHub Pages and can be accessed via the live URL once published.
